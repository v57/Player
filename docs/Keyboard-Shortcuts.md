# Keyboard Shortcuts

Player's playback keys work wherever the focus is in its window.

## Files

| Shortcut | Action |
|---|---|
| ⌘O | **File ▸ Open…** |
| ⇧⌘O | **File ▸ Open from Device…** |
| ⌘, | **Player ▸ Settings…** |

## Playback

| Shortcut | Action |
|---|---|
| Space, Return or keypad Enter | Play or pause |
| ← | Back 5 seconds |
| → | Forward 5 seconds |
| ⌘← or F5 | **Playback ▸ Previous Chapter** |
| ⌘→ or F6 | **Playback ▸ Next Chapter** |
| Esc | Leave full screen |

Holding a key down doesn't repeat it.

## Mouse

| Action | Result |
|---|---|
| Click the video | Play or pause |
| Double-click the video | Enter or leave full screen |

## Media keys

| Key | Action |
|---|---|
| Play/pause | Play or pause |
| Next | The next video in the same folder |
| Previous | The previous video in the same folder |

## In sheets

In **Open from Device…**, **Esc** cancels.
